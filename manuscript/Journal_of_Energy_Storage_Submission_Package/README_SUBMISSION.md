# Submission Package for Journal of Energy Storage (Elsevier)

Manuscript Title: Comparative Benchmark of State-of-Charge Observers and Physics-Informed Neural Networks Across Battery Aging and Thermal Regimes
Authors: Huy Hoang Le, Kim-Anh Nguyen (Corresponding Author)

## Package Contents

1. `manuscript_energy_storage.pdf`: Compiled full-length manuscript in standard Elsevier submission format with line numbers and single-column 12pt layout.
2. `manuscript_energy_storage.tex`: Clean LaTeX source code using standard `elsarticle` class without restrictive ASME template macros or page caps.
3. `references.bib`: Complete BibTeX database containing all 51 references.
4. `figures/`: High-resolution figures (Fig. 1 to Fig. 11).
5. `COVER_LETTER_JOURNAL_OF_ENERGY_STORAGE.md`: Cover letter addressed to Prof. Dirk Uwe Sauer, Editor-in-Chief of Journal of Energy Storage.
6. `FLAT_SOURCE_FOR_ELSEVIER_EDITORIAL_MANAGER/`: Self-contained folder with all files in a single flat directory, ready to be directly uploaded or zipped for Elsevier Editorial Manager.
